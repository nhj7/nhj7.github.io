# 클로드 코드용 빌드 프롬프트 — 금융공모전 카드뉴스 인포그래픽 (10장)

아래 전체를 복사해 Claude Code에 붙여 넣으세요.

---

## 요청

금융 보안 캠페인용 **카드뉴스 인포그래픽 10장**을 코드로 만들어 줘. 체험수기 「본인을 증명할 수 없게 된 날」을 바탕으로 한 시리즈야. 결과물은 화면에서 보기 좋고, 각 카드를 PNG로 내려받을 수 있어야 해.

## 산출물 / 기술 방식

- **단일 HTML 파일**(`index.html`) 하나로 만들어 줘. CSS와 JS는 같은 파일 안에 둬.
- 10장의 카드를 세로로 나열하고, 각 카드는 **정사각형 1:1 (1080×1080px)** 캔버스로 만들어. 화면에서는 적당히 축소해 보여주되 실제 픽셀은 1080 기준으로.
- 아이콘·일러스트는 외부 이미지 대신 **인라인 SVG로 직접 그려.** 단순한 플랫 벡터 스타일(면 위주, 얇은 선, 둥근 모서리).
- 한글 폰트는 **Pretendard**를 CDN으로 불러와: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css`
- 각 카드마다 "PNG 저장" 버튼을 두고, **html2canvas**(`https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js`)로 해당 카드를 1080×1080 PNG로 내보내도록 해. "전체 저장" 버튼도 하나 둬.
- 외부 네트워크는 위 두 CDN 외엔 쓰지 마. 실제 로고·상표·사진은 절대 넣지 마(전부 코드로 그린 도형/아이콘만).
- 텍스트는 이미지가 아니라 실제 HTML 텍스트로 렌더링해서 또렷하게.

## 디자인 시스템

색은 카드 단계별로 바뀐다.

- **A 단계(1~4장, 긴장된 톤)**: 배경 딥네이비 `#0E1A2B`, 보조 `#14202E`, 본문 텍스트 `#EaF0F6`, 포인트 청록 `#3FB6A8`, 경고 레드(절제) `#D86A6A`.
- **B 단계(5~9장, 정보 톤)**: 배경 화이트 `#FFFFFF` / 연회색 `#F4F7FB`, 텍스트 `#16263A`, 포인트 블루 `#2D6BE0`. 9장만 주의색 앰버 `#E8A33D` 추가.
- **C 단계(10장, 따뜻한 마무리)**: 크림 `#FFF6EC` → 연블루 `#EAF2FB` 그라데이션 배경, 텍스트 `#2A3A4A`, 부드러운 블루 포인트.

레이아웃 규칙:
- 카드 안 여백(safe margin) 80px.
- 좌상단에 진행 표시(`01 / 10` 형태, 작게, 흐린 색).
- 헤드카피: Pretendard 800, 큼직하게(대략 64~84px), 2줄 이내.
- 본문: Pretendard 400~500, 36~40px, 줄간 1.5, 2~3줄.
- 일러스트는 카드 하단~중앙에 배치, 헤드/본문과 겹치지 않게.
- 표지(1장)와 마무리(10장)에는 하단에 꼬리표 "제21회 금융공모전 출품작".
- 명도 대비는 본문 가독성이 충분하도록(WCAG AA 수준).

## 카드별 내용과 일러스트 사양

각 카드의 텍스트는 아래 문구를 그대로 써. 일러스트는 설명대로 SVG로 그려.

**1장 · 표지 (A단계)**
- 헤드카피: 이제 그 인증, 못 믿습니다.
- 본문: 휴대폰 인증이 흔들린 봄, 화면 뒤의 이틀과 우리가 지켜야 할 것들
- 꼬리표: 제21회 금융공모전 출품작
- 일러스트: 어두운 배경에 홀로 켜진 모니터 한 대, 화면 속에 은은히 빛나는 자물쇠 아이콘. 청록색 화면광.

**2장 · 무슨 일이 있었나 (A단계)**
- 헤드카피: 바깥의 자물쇠가 부서졌다
- 본문: 2025년 봄, 한 통신사가 해킹당해 약 2,500만 명의 유심 정보가 유출됐습니다. 전 국민의 절반에 가까운 숫자였습니다.
- 일러스트: 줄지어 선 사람 실루엣(브랜드 없는 일반 형태) + 배경에 흩어지는 데이터 점/선. 2,500만이라는 큰 수를 강조하는 큰 숫자 타이포를 일러스트로 활용해도 좋음.

**3장 · 왜 금융까지 위험했나 (A단계)**
- 헤드카피: 가짜가 '진짜 나'가 될 수 있다
- 본문: 휴대폰 인증은 '이 번호가 이 사람의 것'이라는 통신사의 보증에 기댑니다. 유심이 복제되면 그 보증이 가짜에게 넘어가, 계정과 비밀번호까지 바뀔 수 있습니다.
- 일러스트: 똑같이 생긴 스마트폰 두 대. 하나엔 체크(청록), 하나엔 물음표(레드). 둘 사이 점선 화살표로 복제 암시.

**4장 · 화면 뒤의 이틀 (A단계)**
- 헤드카피: 금융을 멈출 수도, 사기를 둘 수도 없었다
- 본문: 금융사들은 통신사 인증을 닫고 한 겹을 더 세워야 했습니다. 세 명의 개발자가 이틀 동안 매달려 '신분증 촬영·진위 확인·얼굴 대조' 인증을 새로 붙였습니다.
- 일러스트: 모니터 앞 사람 실루엣 셋 + 화면 속 추상 코드 라인/흐름도. 시계·시각 표시는 넣지 말 것.

**5장 · 핵심 교훈 / 전환 (B단계 시작)**
- 헤드카피: 하나가 무너지면, 무엇이 남습니까?
- 본문: 편리하다는 이유로 너무 많은 거래가 '휴대폰 인증' 하나에 매달려 있었습니다. 한 수단이 뚫려도 다른 수단이 받쳐 주도록, 인증은 여러 겹이어야 합니다.
- 일러스트: 중앙 스마트폰을 감싼 반투명 방패 3~4겹. 바깥 한 겹은 금이 갔지만 안쪽은 멀쩡.

**6장 · 방어선 1 (B단계)**
- 헤드카피: 방어선 1. 유심(USIM) 보호 서비스
- 본문: 타인이 내 명의로 유심을 복제·개통하지 못하게 막는 통신사 서비스입니다. 이용 중인 통신사 앱이나 고객센터에서 바로 신청할 수 있습니다.
- 일러스트: 유심 칩 위에 잠긴 자물쇠 + 보호막. 깔끔한 아이콘.

**7장 · 방어선 2 (B단계)**
- 헤드카피: 방어선 2. 여신거래 안심차단
- 본문: 나도 모르게 신규 대출·카드 발급이 일어나지 않도록 막는 제도입니다. 금융회사에 한 번 신청해 두면 전 금융권의 신규 여신이 실시간으로 차단됩니다.
- 일러스트: 대출 서류·카드 아이콘 앞을 차단 게이트/방패가 막는 모습.

**8장 · 방어선 3 (B단계)**
- 헤드카피: 방어선 3. 비밀번호는 다르게, 인증은 한 겹 더
- 본문: 포털·메일·금융 앱 비밀번호를 모두 다르게 쓰면 하나가 뚫려도 연쇄 피해를 막습니다. 로그인·이체에는 문자 외에 생체인증이나 OTP를 함께 켜 두세요.
- 일러스트: 서로 다른 모양의 열쇠 여러 개 + 지문/OTP 아이콘.

**9장 · 방어선 4 (B단계 + 앰버 포인트)**
- 헤드카피: 평소엔 점검, 의심되면 즉시
- 본문: 명의도용방지 서비스로 내 명의 휴대폰 개통 내역을 확인할 수 있습니다. 피해가 의심되면 곧바로 112·1332로 신고하고 계좌 지급정지를 요청하세요.
- 일러스트: 체크리스트 클립보드 + 긴급 전화 수화기/방패 아이콘. 앰버 포인트로 '즉시' 강조.

**10장 · 마무리 (C단계)**
- 헤드카피: 함께 지킬 때, 비로소 안전합니다
- 본문: 인증이 한 단계 늘어나는 번거로움은 사실 나를 지키는 울타리입니다. 보이지 않는 곳의 만드는 사람과 화면 앞의 당신이 만날 때, 금융은 비로소 안전해집니다.
- 꼬리표: 제21회 금융공모전 출품작
- 일러스트: 따뜻한 아침 창가, 스마트폰을 보는 사람 실루엣과 뒤에서 받치는 또 다른 실루엣이 부드럽게 겹침.

## 마무리 요청

- 먼저 전체 구조를 잡고, 공통 카드 컴포넌트(헤드/본문/일러스트 슬롯/진행표시/꼬리표)를 만든 뒤 10장을 채워 줘.
- 완성하면 브라우저에서 바로 열어 확인할 수 있게 하고, 각 카드 PNG 저장이 실제로 동작하는지 확인해 줘.
- SVG 일러스트는 과하지 않게, 단순하고 일관된 스타일로.
